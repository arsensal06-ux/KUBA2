# 2.0 — доработка

- Добавлены `defaults.js`, `config.js`, `store.js`, `site.js`, `admin.js`.
- Перенесена логика из встроенных script в отдельные модули без необходимости сборщика.
- Унифицированы настройки, туры, реальная авторизация и live-подписки.
- Добавлены WebP-обложки, палитра, формы заявок, детали туров, контакты, статистика.
- Добавлены безопасные шаблоны, fallback для изображений, feedback об ошибках.
- Добавлены deploy-конфигурация, серверные правила, локальное демо и E2E-тест.
- Старые локальные псевдо-сессии больше не используются. Старые `kab_bookings` не переносились в облако автоматически, чтобы не публиковать неподтверждённые персональные данные.
