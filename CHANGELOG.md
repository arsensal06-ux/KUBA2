# 2.0 — доработка

- Добавлены `defaults.js`, `config.js`, `store.js`, `site.js`, `admin.js`.
- Перенесена логика из встроенных script в отдельные модули без необходимости сборщика.
- Унифицированы настройки, туры, реальная авторизация и live-подписки.
- Добавлены WebP-обложки, палитра, формы заявок, детали туров, контакты, статистика.
- Добавлены безопасные шаблоны, fallback для изображений, feedback об ошибках.
- Добавлены deploy-конфигурация, серверные правила, локальное демо и E2E-тест.
- Старые локальные псевдо-сессии больше не используются. Старые `kab_bookings` не переносились в облако автоматически, чтобы не публиковать неподтверждённые персональные данные.

# 2.1 — GitHub Pages без локальных программ

- Добавлен `.github/workflows/deploy.yml`: проверка файлов, подготовка сайта, публикация через Pages при push в main/master и ручном Run workflow.
- В архиве файлы сразу в корне, без обязательной вложенной папки проекта.
- Добавлены браузерная страница `setup.html` и ссылки на неё из админки.
- Проверка подключения на setup не требует введения секретов и не меняет базу.
- Убраны инструкции Firebase Hosting/CLI; основной сценарий — GitHub Pages + Firebase Console через браузер.
- Технические сообщения о базе оставлены владельцу в админке и setup, но скрыты от клиентов главной страницы. Сообщения об ошибках входа/отправки остаются.
